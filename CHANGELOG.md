## [1.0.0] - 2026-07-29

### Added
- Plugin marketplace registry for Claude Code
- **github-init** plugin — automates GitHub project creation with personalized preferences
- **repofinery** plugin — audits and transforms repos across 20 categories
- Marketplace supports GitHub shorthand, HTTPS, and SSH installation methods
