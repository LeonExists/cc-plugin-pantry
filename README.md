# cc-plugin-pantry

A pantry of plugins and skills for [Claude Code](https://docs.anthropic.com/en/docs/claude-code) — grab what you need, leave what you don't.

## What's inside

This repo is a curated collection of personally crafted Claude Code plugins and skills. Browse the shelves, pick what's useful, and drop it into your setup.

| Section | Description |
|---------|-------------|
| `plugins/` | Installable Claude Code plugins |
| `skills/` | Standalone skills to add to your workflow |

## Installation

### Plugins

```bash
claude plugin add LeonExists/cc-plugin-pantry/plugins/<plugin-name>
```

### Skills

Copy the skill file into your `.claude/skills/` directory, or reference it directly.
