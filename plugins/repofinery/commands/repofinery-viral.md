## Viral Optimization Tactics

When proposing fixes in this mode, think like a marketer:

- **README rewrite:** Lead with the hook, not the description. "X in Y seconds" or "Never Z again"
- **Tagline:** Short, punchy, slightly provocative. Test: would this work as a tweet?
- **GIF/demo:** The first 3 seconds must show the "wow moment"
- **Comparison:** Always suggest a "before/after" or "us vs them" visual
- **Social proof:** Badges, star count, "Used by X" section
- **Emotional hook:** Frame the problem as a pain point everyone relates to
- **One-liner install:** The path from "interested" to "trying it" must be one command

## Visual Asset Approach

In this mode, proactively suggest visual assets:

- Propose a before/after comparison image
